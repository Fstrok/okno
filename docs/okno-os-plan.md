# Okno OS — план (на утверждение)

## 0. Честно про «с нуля»

- **Своё ядро, драйверы и свой Win32 — нет.** ReactOS делает совместимую с Windows ОС с 1998 года и до сих пор альфа.
  Haiku за 25 лет — бета с узким кругом железа. Google делал Fuchsia ~8 лет сотнями инженеров и выпустил на одном
  устройстве. Драйверы Linux — десятки миллионов строк, Wine — 30 лет работы. Повторять это = не выпустить никогда.
- **С нуля делаем продукт**, то, чем человек пользуется: сборку системы, оболочку, запуск .exe, установку из-под Windows,
  переезд, обновления, «Параметры». Ядро Linux, KDE, Wine/Proton — готовые детали.
- **Отличие от Zorin/Mint/Bazzite — доводка, а не технология**: .exe работает двойным кликом без ручных настроек,
  установка без флешки прямо из Windows с переносом данных, атомарные обновления с откатом, российский набор.
  «Ещё один дистрибутив с темой под Windows» никому не нужен (Linuxfx/Wubuntu так и остались никем).
- **Рынок**: Windows ~57% настольных, Linux ~4,4% в мире (StatCounter, июнь 2026). Бесплатные обновления Windows 10
  для домашних продлены до 12.10.2027 и закончатся; миллионы ПК не тянут Windows 11. Это аудитория v1.

## 1. Продукт

Okno OS — система для домашних ПК и ноутбуков x86_64 вместо Windows 10/11:

- выглядит и ведёт себя привычно: Пуск, панель задач, Проводник, Параметры, Диспетчер задач, те же горячие клавиши;
- .exe/.msi запускаются двойным кликом, попадают в Пуск, удаляются из «Параметров»;
- ставится из-под Windows одной программой, без флешки и BIOS, рядом с Windows, с переносом файлов и настроек;
- обновляется сама целиком; неудачное обновление откатывается само;
- на русском; КриптоПро, Рутокен, плагин Госуслуг, 1С — из коробки.

Не в v1: компании (домен AD, групповые политики), ARM-ноутбуки, планшеты. Okno для телефона живёт отдельно и не меняется.

## 2. Архитектура

- **Ядро и драйверы — Fedora.** Подписаны ключом, которому доверяет Secure Boot: ставится без его отключения.
  Свежие ядро и Mesa каждые полгода — новое железо работает. Debian (как в Okno для телефона) отпадает: старые
  ядро/Mesa и нет готового атомарного конвейера.
- **Основа — Fedora Atomic через bootc, образ Universal Blue `kinoite-main`.** Система = OCI-образ из Containerfile,
  собирается в GitHub Actions, обновляется атомарно с откатом. Так сделаны Bazzite и Aurora — проверено массово.
  NVIDIA — модули из `ublue-os/akmods`, отдельный вариант образа.
- **Оболочка — KWin + Plasma 6, поверх наша на QML**: Пуск, панель задач, уведомления, Alt+Tab, Win-клавиши
  (Win+E, Win+D, Win+L, Win+стрелки, Win+V, Win+Shift+S, Ctrl+Shift+Esc). Свой композитор — годы
  (System76 делала COSMIC ~3 года командой).
- **Свои приложения** там, где пользователь Windows теряется: «Параметры» со структурой Windows (внутри — модули KDE),
  Диспетчер задач, установщик, мастер первого запуска, центр программ.
- **Проводник — Dolphin** с нашей настройкой: «Этот компьютер», диски, библиотеки, двойной клик.
- **Свои программы — Flatpak/Flathub**: песочница, десятки тысяч программ, обновления без нас.
- **Безопасность**: Secure Boot, SELinux, шифрование LUKS2 с разблокировкой через TPM2 (аналог BitLocker).
- **Вид**: своя тема «Okno»; шрифт Selawik — открытая замена Segoe UI от самой Microsoft, совпадает по метрикам,
  поэтому окна Windows-программ не разъезжаются; Carlito/Caladea/Liberation для документов Office.
  Логотипы, иконки, звуки, обои и Segoe UI от Microsoft не берём — товарные знаки и лицензии.

## 3. Windows-программы — «Okno Run» (главная ценность)

- Двойной клик по .exe/.msi/.lnk/.bat/.reg → определяем программу (хеш, данные PE, тип установщика:
  Inno/NSIS/MSI/InstallShield) → берём рецепт из базы → отдельный префикс на программу → ставим нужное
  (VC++ runtime, .NET, шрифты, DXVK/VKD3D) → запускаем через Proton (umu-launcher) или Wine.
- После установки: ярлыки — в наш Пуск с иконками, ассоциации файлов, запись в «Параметры → Приложения» с удалением.
- База рецептов — открытый репозиторий YAML (версия Proton/Wine, winetricks, переменные, подмены DLL).
  Затравка — protonfixes, winetricks, ProtonDB. Отчёт «работает / нет» одной кнопкой (по согласию) — база растёт сама.
- Каталог: манифесты winget-pkgs (MIT, тысячи программ с прямыми ссылками) → «Установить» в один клик;
  рядом — родная Linux-версия, если есть.
- Игры: Steam (Proton), Epic/GOG через Heroic, ярлыки в Пуск.
- Помощник Claude (опционально, ключ или подписка пользователя) на клавише Copilot (Win+Shift+F23): чинит
  «программа не запускается», подбирает рецепт, управляет рабочим столом через портал RemoteDesktop —
  опыт `okno-screen` из Okno для телефона.

**Потолок, который не пробить:**

- игры с античитом в ядре — Valorant, League of Legends, Fortnite, Call of Duty, Battlefield 6 — не заработают
  без их разработчиков;
- Adobe Creative Cloud, свежий Microsoft Office для ПК, AutoCAD — плохо или никак. Замена: OnlyOffice/Р7/LibreOffice,
  Office в браузере, Krita/GIMP/Photopea;
- всё, что ставит свои драйверы Windows (.sys): донглы, часть принтеров и сканеров.

## 4. Установка и переезд (вторая главная ценность)

1. **Okno Setup.exe** (Rust, один файл, Windows 10/11 без зависимостей):
   - железо: UEFI, Secure Boot, процессор, видеокарта, Wi-Fi по PCI ID → «работает / с оговоркой / не работает»;
   - программы: список установленного из реестра → по каждой «есть родная версия / Okno Run / в браузере / не работает»;
   - BitLocker: находит и сохраняет ключ восстановления;
   - сам ужимает C: средствами Windows (работает и с BitLocker), создаёт раздел, качает установщик,
     прописывает загрузку в UEFI, перезагружает;
   - пакет переезда: Документы, Рабочий стол, Изображения и т.д., закладки и профили браузеров,
     Wi-Fi сети с паролями (`netsh wlan export`), обои, раскладки, список программ.
2. **Установщик** (QML поверх `bootc install`): рядом с Windows (по умолчанию) или вместо; шифрование по желанию.
3. **Первый запуск**: язык, пользователь, Wi-Fi уже есть, импорт пакета переезда, установка найденных программ.
4. Позже — кнопка «Удалить Windows и вернуть место».
5. Запасной путь — ISO на флешку для чистой установки.

## 5. Обновления и инфраструктура

- Образ `ghcr.io/fstrok/okno-os` (+ `-nvidia`), сборка в GitHub Actions на каждый пуш, подпись cosign.
- Каналы: testing (каждая сборка) → stable (раз в неделю после тестов).
- Обновление качается в фоне, применяется при перезагрузке; не загрузилась — автооткат (greenboot).
  /home и Windows-префиксы не затрагиваются.
- Автотесты в CI: загрузка в QEMU с OVMF + Secure Boot до рабочего стола, снимок экрана,
  прогон набора .exe (топ-50) через Okno Run → процент успешных в отчёте сборки.
- GitHub Releases не берёт файлы больше 2 ГБ → установщик маленький, систему тянет из ghcr.io;
  полный ISO — Cloudflare R2 (бесплатный тариф).
- Телеметрия только по согласию: железо и совместимость программ.

## 6. Этапы

- **Этап 0 — проверка рискованного, 2–3 недели.** (1) Образ bootc собирается в CI и грузится в QEMU с Secure Boot
  до рабочего стола; (2) Okno Run v0 на 20 популярных установщиках; (3) установка из Windows в ВМ без флешки.
  *Готово, когда* все три работают в ВМ и измерен исходный процент успешных .exe — от него ставим цель на 1.0.
- **Этап 1 — альфа, +1,5 месяца.** Конвейер образов, ISO, тема, Пуск и панель задач, Win-клавиши, Проводник,
  Okno Run v1 + база на 50 программ, автообновление с откатом.
  *Готово, когда* ставится и обновляется на 3–5 реальных ПК (Intel, AMD, NVIDIA).
- **Этап 2 — бета, +2–3 месяца.** Okno Setup.exe с отчётом совместимости, установка без флешки, переезд,
  «Параметры», первый запуск, российский набор, принтеры и сканеры, NVIDIA, LUKS + TPM2.
  *Готово, когда* человек без опыта Linux сам ставит систему из Windows и переносит данные.
- **Этап 3 — 1.0, +2–3 месяца.** Центр программ (Flathub + winget), отчёты совместимости, помощник Claude,
  сайт, отчёты о сбоях. *Готово, когда* топ-100 Windows-программ проходят двойным кликом на уровне цели из этапа 0
  и 30 дней обновлений без поломок на тестовых ПК.
- **После 1.0**: ARM64 (Snapdragon X, опыт FEX/Hangover из Okno), предустановка у сборщиков, компании (AD через SSSD).

До 1.0 — 7–9 месяцев. Узкое место не код, а проверка на реальном железе.

## 7. Риски

- **Совместимость .exe ниже ожиданий** — меряем на этапе 0, до основных вложений. Плохо — смещаем упор на родные
  программы и веб.
- **Железо** (Wi-Fi, сон, сканеры отпечатков на отдельных ноутбуках) — база железа и предупреждение до установки.
- **Universal Blue меняет базу** — наш Containerfile; уход на чистую Fedora bootc = замена одной строки `FROM`.
- **Доступ к GitHub/ghcr.io из РФ** — зеркало образа на своём сервере, если начнутся блокировки.
- **Один разработчик** — всё, что не отличает продукт, берём готовым.

## 8. На утверждение

1. Основа: x86_64 ПК; Fedora Atomic/bootc (Universal Blue) + Plasma с нашей оболочкой; Proton/Wine.
2. Новый репозиторий под систему — `Fstrok/okno-os`; Okno для телефона остаётся здесь.
3. Реальный ПК или ноутбук для тестов к этапу 1 (остальное закрывают ВМ); лучше с NVIDIA — самый проблемный случай.
4. Название — «Okno».
